# Business Intelligence Analytics System

## Project Overview
This project analyzes retail sales data using Python, SQL, ETL,
Power BI, and machine learning-based sales forecasting.

## Technologies Used
- Python
- Pandas and NumPy
- SQLite and SQL
- Matplotlib
- Scikit-learn
- Power BI

## Dataset
The Superstore dataset contains 9,994 transaction records.
The forecasting dataset includes order dates and sales values.

## Key Features
- Sales and profit KPI analysis
- Regional and category-wise sales analysis
- SQL-based business queries
- ETL data cleaning and loading
- Interactive Power BI dashboard
- Monthly sales forecasting

## Forecasting Evaluation
Random Forest:
- MAE: 13,764.75
- RMSE: 15,995.80

Seasonal baseline:
- MAE: 18,031.99
- RMSE: 20,424.97

The Random Forest model performed better on the 12-month test
period. Forecasts are estimates, not actual sales.

## Main Deliverables
- Power BI dashboard (.pbix)
- SQLite database (.db)
- Colab notebook (.ipynb)
- ETL script (.py)
- Forecast CSV and visualization
- Model evaluation results (.csv)
